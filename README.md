# Quantum

Quantum is a powerful new web browser built on Electron. It's designed from scratch to be a lightweight, fast, and secure alternative to traditional browsers. With a focus on a minimal UI and powerful features, Quantum gives you complete control over your browsing experience. This project marks a fresh start, replacing the legacy **PySurf** project with a modern, more efficient architecture.

> [!IMPORTANT]
> Quantum is in early stages of development. Please report any issues/bugs.
>

✨ Key Features
--------------
*   **⚡️ Blazing Fast:** Leveraging Electron and an optimized codebase for lightning-fast performance.    
*   **🔒 Enhanced Privacy:** Built-in features to protect your data and browsing history.
*   **📚 Built-in Tools:** Integrated bookmarks, history, and downloads managers.    
*   **🖱️ Smart Context Menu:** Right-click anywhere for quick access to essential navigation and developer tools.
*   **⚙️ Sidebar:** Use the sidebar on the right for easy access to important features.
